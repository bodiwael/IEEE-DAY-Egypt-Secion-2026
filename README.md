# IEEE Day 2026 – v2

## Files
- `Master_Sheet.xlsx` – YOUR sheet + new columns (National ID, T-Shirt Size, Phone) + `Staff` sheet. Fill it, it is the single source of data.
- `staff_codes.csv` – each staff member's Staff ID + private access code (hand out individually, never publish).
- `build.py` – turns the sheet into the app. Run after ANY change to the sheet:  `pip install openpyxl cryptography` then `python3 build.py`
- `site/` – upload this to Netlify / Cloudflare / Vercel / GitHub Pages.
- `backend/Code.gs` – paste into Google Sheet > Extensions > Apps Script (regenerated by build.py).

## Setup (first time, or after upgrading from v1)
1. Google Sheet > Extensions > Apps Script: replace ALL code with `backend/Code.gs`. If you used v1, DELETE the old `Events` and `Mail` tabs first (new layout).
2. Put your email in `TEST_TO` while testing. Run `setup` once. Deploy > New deployment > Web app > Execute as Me > Anyone. Copy the /exec URL.
3. Locally: in `site/` run `python3 -m http.server 8000`, open `http://localhost:8000/?api=YOUR_EXEC_URL`.
4. Sign in with a Staff ID + code from staff_codes.csv (e.g. R1, or ADMIN).
5. Host: drag `site/` to app.netlify.com/drop. Phones open `https://SITE/?api=YOUR_EXEC_URL` once online, Add to Home Screen.
6. Before the event: `TEST_TO=''`, Deploy > Manage deployments > New version. Clear test rows in Events and Mail tabs.

## Changing staff / bus assignments
Edit the `Staff` sheet (Staff ID, Name, Role, Bus, Point, Email), run `python3 build.py`, re-upload `site/`, paste the new `Code.gs`, deploy a new version. Existing staff keep their codes.
